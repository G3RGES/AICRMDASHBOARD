# TTP CRM Frontend

Frontend application for the TTP CRM platform.

## Features

- Interactive CRM Dashboard
- Lead Management Interface
- Sales Pipeline Visualization
- Revenue Analytics
- Follow-up Tracking
- AI Sales Insights Panel
- Responsive Design
- Authentication & Authorization

## Tech Stack

- React.js
- Vite
- React Router
- Tailwind CSS
- Axios
