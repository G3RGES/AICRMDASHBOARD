# 🎨 TTP CRM Frontend

Frontend application for the **TTP CRM** platform, built with **React** and **Vite**. It provides a modern, responsive interface for managing leads, contacts, sales pipelines, follow-ups, analytics, and AI-powered CRM features.

---

## ✨ Features

### 📊 Dashboard

- Business overview
- Revenue & pipeline analytics
- Interactive charts
- KPI cards
- AI Sales Insights

### 👥 Lead Management

- Create, edit, and delete leads
- Search & filtering
- Status management
- Priority management
- Lead details

### 📇 Contact Management

- Contact directory
- Company information
- Tags & notes
- Search functionality

### ✅ Follow-ups & Tasks

- Task management
- Progress tracking
- Due dates
- Lead associations
- Status filtering

### 🤖 AI Features

- AI Lead Summary
- AI Email Generator
- AI Pipeline Insights
- Pipeline Health Score

### 🔐 Authentication

- Login & Registration
- Protected routes
- JWT-based authentication
- Persistent sessions

### 🎨 UI/UX

- Responsive design
- Modern dashboard layout
- Reusable UI components
- Loading states
- Toast notifications
- Clean navigation

---

## 🛠 Tech Stack

- React.js
- Vite
- React Router DOM
- Tailwind CSS
- Axios
- Lucide React
- Recharts
- Sonner

The frontend communicates with the **TTP CRM Backend** through a REST API built with Express.js and MongoDB.
