# ⚙️ TTP CRM Backend

RESTful API for the **TTP CRM** platform, built with **Node.js**, **Express.js**, and **MongoDB**. It provides secure authentication, CRM management, analytics, and AI-powered features using the Google Gemini API.

---

## ✨ Features

### 🔐 Authentication & Authorization

- JWT authentication
- User registration & login
- Protected routes
- Password hashing with bcrypt

### 👤 User Management

- User profiles
- Profile updates
- Secure authentication middleware

### 👥 Lead Management

- Full CRUD operations
- Lead pipeline tracking
- Priority management
- Source tracking
- Search & filtering

### 📇 Contact Management

- Full CRUD operations
- Contact notes
- Tags
- Company information

### ✅ Task Management

- Create, update, delete tasks
- Due dates
- Priorities
- Status tracking
- Lead & contact associations

### 📊 Analytics

- Dashboard statistics
- Revenue metrics
- Pipeline insights
- Business KPIs

### 🤖 AI Integration

Powered by **Google Gemini**

- AI Lead Summary
- AI Sales Insights
- AI Email Generator
- Structured JSON responses
